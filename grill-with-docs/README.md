# grill-with-docs

A relentless interview to sharpen a plan or design that also records settled terms in `GLOSSARY.md` (and, rarely, decisions as ADRs) as it goes. It is a one-line shortcut: it calls [grilling](https://github.com/mattpocock/skills/tree/main/skills/productivity/grilling) and this repo's [domain-modeling](../domain-modeling) together, the same pairing [wayfinder](../wayfinder) uses for its grilling tickets. Use it for a design conversation that doesn't need a full map.

Copied unchanged from Matt Pocock's [grill-with-docs](https://github.com/mattpocock/skills/tree/main/skills/engineering/grill-with-docs) (MIT) at upstream commit `49dd158`. No divergences; the adaptations live in `domain-modeling`.

User-invoked only: `/grill-with-docs <plan or idea>`.
