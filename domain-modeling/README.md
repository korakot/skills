# domain-modeling

Sharpen a project's vocabulary while you design: challenge terms against the glossary, propose one precise word for a vague one, probe concept boundaries with edge-case scenarios, and record settled terms in `GLOSSARY.md` (and, rarely, decisions as ADRs).

A fork of Matt Pocock's [domain-modeling](https://github.com/mattpocock/skills/tree/main/skills/engineering/domain-modeling) (MIT), adapted for wiki repos: entries are written only once a term is settled, and they link to wiki pages instead of restating them. Details: [`UPSTREAM.md`](UPSTREAM.md).

Triggers on its own when terminology is being discussed. [wayfinder](../wayfinder) calls it alongside grilling.

## Install

Claude.ai: upload `domain-modeling.skill` in **Settings → Customize → Skills**. Claude Code: copy the folder into `.claude/skills/`.
